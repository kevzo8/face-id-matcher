What is the SVI Liveness SDK?

A client-side JavaScript SDK that detects whether a user is a real person (not a photo, video, or mask) using their device camera.

Passive Liveness

Single snapshot analyzed locally with MediaPipe:

  • Face size & position
  • Head roll angle
  • Image sharpness
  • Brightness level

Takes ~1 second

Active Liveness

6 challenge steps the user must perform:

  • Look straight (stillness)
  • Blink slowly
  • Turn head left / right
  • Look up / down

Takes ~13 seconds

Both return a score (0–100%) and pass/fail decision.

Architecture

Browser (SDK)

  • SviPassiveLiveness — snapshot + local scoring
  • SviActiveLiveness — 6 challenge steps
  • SviLivenessCore — camera, session, API helpers
  • detector.ts — MediaPipe FaceLandmarker wrapper
  • ui.ts — Card UI with overlays

Backend (FastAPI)

  • POST /api/v1/session/create
  • POST /api/v1/liveness
  • POST /liveness/detect-faces (AWS)
  • POST /liveness/detect-objects (AWS)
  • GET /health

Passive Liveness Flow

1
Initialize — POST /api/v1/session/create
2
Start camera — getUserMedia
3
Capture frame — Video to Canvas
4
Detect face — MediaPipe FaceLandmarker
5
Score — 5 metrics below
Metric         Max  What it checks
Face Size       15  Face width in frame
Centering       10  Nose between ears
Head Tilt       10  Eye line angle (roll)
Sharpness       10  Pixel variance (blur)
Brightness       5  Average luminance
TOTAL           50  Pass: >= 35 (70%)

All scoring is local. No images leave the browser.

Active Liveness Flow

1
Session + Camera — same setup
2
6 Challenges — each with countdown timer
3
Snapshot — captured during "Look straight"
4
Score — per-step (0-15) summed vs 70% threshold
Challenge      Dur.  Measured
Look straight   2s   Stillness
Blink slowly    3s   Blink count
Turn left       2s   Yaw movement
Turn right      2s   Yaw movement
Look up         2s   Pitch movement
Look down       2s   Pitch movement
Max: 90 pts (6 x 15)  Pass: >= 63 (70%)

SDK Integration (3 Steps)

Step 1

Add the script tag.

Step 2

Add a container div.

Step 3

Initialize with SviLiveness.create().


<script src="svi-liveness.dev.js"></script>


<div id="svi-root"></div>


<script>
var sdk = SviLiveness.create({
  backendUrl:  'http://localhost:8000',
  mode:        'passive',   // 'passive' | 'active'
  containerId: 'svi-root',
  onComplete:  function(result) {
    console.log('Passed:', result.passed);
    console.log('Score:', result.score + '%');
    console.log('Face:', result.capturedFaceBase64
      ? 'captured' : 'none');
  },
  onError:     function(err) {
    console.error(err.code, err.message);
  },
  theme: { primaryColor: '#3b82f6' },
});

sdk.start();  // begins camera + detection
</script>

SDK handles camera, UI, challenges, and scoring. No CDN or external dependencies needed.

Backend API Reference

POST /api/v1/session/create

Creates a one-time session.

// Request (Headers only, no body)
Authorization: Bearer <key>

// Response 200
{ "session_id": "uuid",
  "expires_at": "2026-07-28T..." }

POST /api/v1/liveness

Returns liveness result + captured face image.

// Request
{ "mode":  "active|passive",
  "image": "base64...",
  "session_id": "uuid",
  "challenge_data": null }

// Response 200
{ "passed":      true,
  "confidence":  0.85,
  "txn_id":      "uuid",
  "provider":    "heuristic",
  "used_fallback": false,
  "captured_face": "base64...",
  "error":        null }

POST /liveness/detect-faces (AWS)

// Request:  { "image": "base64..." }
// Response: { "face_detected": true,
//             "confidence": 0.99,
//             "eyes_open": true,
//             "quality_sharpness": 0.8,
//             "age_low": 25, "age_high": 35,
//             "gender": "Male", "expression": "Happy" }

POST /liveness/detect-objects (AWS)

// Request:  { "image": "base64..." }
// Response: { "has_phone": false,
//             "has_screen": false,
//             "has_photo": false,
//             "spoof_risk": "low",
//             "raw_labels": [...] }

GET /health

Running Locally

Prerequisites

  • Python 3.14+
  • Node.js 20+ (SDK rebuild)
  • Webcam

1. Backend

cd backend
pip install -r requirements.txt
python run.py

Starts at http://localhost:8000

2. Demo page

cd sdk
python -m http.server 3000

Open http://localhost:3000/demo/

3. Rebuild SDK (optional)

cd sdk
npm install
npm run build

Outputs in dist/

Tip

Open F12 console → API logs tagged [SESSION] and [LIVENESS] with full request/response payloads.

Key Design Decision

The SDK does all scoring client-side using MediaPipe. The backend is for session management, audit logging, and optional cloud provider fallbacks.

No images leave the browser unless you explicitly call the API.
